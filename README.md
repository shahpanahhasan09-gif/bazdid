# سامانه بازدید مناطق

وب‌اپ فارسی و موبایل‌محور برای ثبت، پیگیری و گزارش مشکلات شهری.

## امکانات
- ثبت عکس قبل و بعد با دوربین موبایل
- ثبت محل، شرح، دسته‌بندی، مسئول و یادآوری
- ساخت کد پیگیری یکتا برای هر پرونده و جستجوی مستقیم با کد
- افزودن چند گزارش مسئول، تاریخ انجام و حداکثر ۳ تصویر برای هر گزارش
- تأیید نهایی گزارش توسط بازرس
- تشخیص تقریبی موارد تکراری
- چک‌لیست کارها، جستجو و فیلتر
- گزارش چاپی و پاورپوینت
- پشتیبان‌گیری و بازیابی JSON
- نصب روی صفحه اصلی و اجرای آفلاین (PWA)

## انتشار روی GitHub Pages
فایل‌های `index.html`، `manifest.webmanifest`، `sw.js` و `icon.svg` را در ریشه مخزن قرار دهید. سپس از Settings → Pages، گزینه Deploy from a branch و شاخه main / root را انتخاب کنید.

> داده‌ها فقط در مرورگر همان گوشی ذخیره می‌شوند. مرتباً از تنظیمات برنامه فایل پشتیبان JSON بگیرید.
