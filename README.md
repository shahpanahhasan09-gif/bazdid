### راه دستی
متن زیر را کپی کن و در چت هوش مصنوعی جدید بفرست:

```text

پروژه یک برنامه تحت وب فارسی و راست‌چین برای مدیریت بازدید و عملیات شهرداری است که روی GitHub Pages منتشر می‌شود.

لطفاً اول این دو آدرس را کامل بخوان، بعد شروع کن:
https://raw.githubusercontent.com/shahpanahhasan09-gif/bazdid/main/BAZDID-HANDOVER.md
https://raw.githubusercontent.com/shahpanahhasan09-gif/bazdid/main/BAZDID-PROJECT-STATUS.md

قواعد ثابت:
۱. فقط از بخش «اقدام بعدی» ادامه بده و پروژه را از نو شروع نکن.
۲. من فقط گوشی دارم؛ راهنمایی‌ها باید موبایلی و با نام دقیق دکمه‌ها باشد.
۳. فایل index.html نسخه تولید v10 را تغییر نده.
۴. هیچ رمز یا کلید محرمانه‌ای از من نخواه و در کد نگذار.
۵. کار را مرحله‌به‌مرحله جلو ببر و بعد از هر مرحله فایل وضعیت را به‌روز کن.
۶. فارسی و خلاصه جواب بده.

بگو تا کجا پیش رفته‌ایم و قدم بعدی دقیقاً چیست.
```

# 📱 اگر گوشی گم شد، دزدیده شد یا سوخت

**پروژه از بین نمی‌رود** — کد برنامه و کل حافظه پروژه روی همین مخزن است، نه روی گوشی.

### چهار کار پیشگیرانه (یک‌بار انجام بده)
| # | کار | آدرس |
|---|---|---|
| ۱ | کدهای بازیابی گیت‌هاب را بگیر و **بیرون از گوشی** نگه دار | <https://github.com/settings/auth/recovery-codes> |
| ۲ | یک **ایمیل دوم** به حساب اضافه کن | <https://github.com/settings/emails> |
| ۳ | هفته‌ای یک‌بار **پشتیبان JSON** برنامه را بگیر و برای خودت بفرست | داخل برنامه → تنظیمات |
| ۴ | رمزها را در **Password Manager** حساب گوگل ذخیره کن | Chrome → تنظیمات |

### بازیابی روی گوشی جدید
۱. ورود به حساب گوگل در کروم
۲. ورود به `github.com` (در صورت نیاز با کد بازیابی)
۳. باز کردن مخزن `bazdid` — همه‌چیز سر جایش است
۴. باز کردن برنامه و افزودن دوباره به صفحه اصلی
۵. بازیابی آخرین فایل پشتیبان JSON
۶. افزودن دوباره [کارت نجات](https://shahpanahhasan09-gif.github.io/bazdid/sos.html) به صفحه اصلی

> ⚠️ تا کامل‌شدن **مرحله ۴ (سینک Supabase)**، داده‌های ثبت‌شده فقط در مرورگر همان گوشی ذخیره می‌شوند. پشتیبان JSON تنها محافظ آن‌هاست.

## ✨ امکانات
- ثبت عکس قبل و بعد با دوربین موبایل
- ثبت محل روی نقشه، شرح، دسته‌بندی، مسئول و یادآوری
- کد پیگیری یکتا برای هر پرونده و جست‌وجوی مستقیم با کد
- چند گزارش برای هر پرونده، تا ۳ تصویر برای هر گزارش
- تأیید نهایی گزارش توسط بازرس و تاریخچه کامل پرونده
- مرکز گزارش‌ها با بازه زمانی شمسی مشترک: گزارش کارتی موبایل، چاپ، ورد، اکسل و پاورپوینت
- ویزارد ۷ گامی ثبت عملیات با تقویم شمسی تمام‌صفحه، GPS اجباری شرطی و مسیریابی گوگل و نشان
- گردش چهارنقشی عملیات: مدیر اصلی ← مدیر اجرایی (با امکان پیشنهاد اصلاح) ← اکیپ اجرا ← ناظر
- ثبت سه‌مرحله‌ای روند عملیات با عکس و موقعیت اجباری و مهر اصالت (مختصات، دقت، زمان، منبع، ثبت‌کننده)
- کارتابل «منتظر اقدام تو»، جست‌وجو، فیلتر وضعیت و نشانه‌های توجه
- پشتیبان‌گیری و بازیابی JSON
- نصب روی صفحه اصلی و اجرای آفلاین (PWA)

## 🚀 انتشار روی GitHub Pages
فایل‌های `index.html`، `manifest.webmanifest`، `sw.js` و `icon.svg` در ریشه مخزن قرار دارند.
مسیر فعال‌سازی: **Settings → Pages → Deploy from a branch → main / root**

> داده‌ها فعلاً فقط در مرورگر همان گوشی ذخیره می‌شوند. مرتباً فایل پشتیبان JSON بگیرید.
